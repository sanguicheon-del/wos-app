# Animation

## Overview
Animation should support the product experience rather than dominate it. The goal is to create motion that feels polished, intentional, and premium.

## Motion Principles
- Use motion to guide attention and clarify transitions.
- Keep movement subtle, smooth, and purposeful.
- Respect user comfort and reduced-motion preferences.
- Avoid excessive or decorative motion.

## Recommended Usage
- Use brief transitions for micro-interactions.
- Use slower, more deliberate motion for larger section reveals.
- Prefer transform and opacity-based transitions for performance.

## Quality Bar
Animation should feel effortless and refined. Motion should reinforce hierarchy and flow while preserving clarity and usability.
