# Folder Structure

## Overview
The repository is organized to separate concerns clearly and support sustainable growth.

## Main Areas
- app/: route entry points, layouts, and page-level composition
- components/: reusable UI primitives and composed sections
- lib/: shared utilities and supporting logic
- public/: static assets
- docs/: project documentation
- prompts/: reusable prompt assets for future AI-assisted workflows
- scripts/: automation and maintenance tools
- .github/workflows/: automation and CI/CD configuration

## Guiding Rule
Each area should have a clear responsibility and remain easy to navigate. New folders should be introduced only when they support a clearly defined purpose.
