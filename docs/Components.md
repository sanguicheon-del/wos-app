# Components

## Overview
Components are the building blocks of the product interface. They should be reusable, predictable, and aligned with the design system.

## Component Categories
- UI primitives: foundational elements such as buttons, typography, cards, and containers.
- Shared components: patterns used across multiple sections or views.
- Section components: feature-specific compositions that build the experience.

## Expectations
- Components should have a single clear purpose.
- Props should be explicit and type-safe.
- Reuse existing primitives before introducing new patterns.
- Keep styling and behavior consistent with the broader system.

## Guidance
New components should improve clarity and reusability rather than adding one-off complexity. If a pattern is useful in multiple contexts, it should be promoted to a shared component.
