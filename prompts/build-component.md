# Build Component Prompt

## Goal
Create a production-ready UI component for the W° OS project that aligns with the existing design system, architecture, and quality bar.

## Scope
- Implement a reusable component for the frontend experience.
- Follow existing project conventions for naming, structure, and styling.
- Ensure the component is appropriate for production use.

## Constraints
- Do not modify source code outside the prompt workflow context.
- Do not introduce unnecessary dependencies.
- Do not break existing application behavior.
- Keep the implementation aligned with the established visual language and accessibility expectations.

## Deliverables
- A well-structured component implementation.
- Clear props and typing.
- Appropriate styling and composition.
- Notes on accessibility, responsiveness, and reusability.

## Acceptance Criteria
- The component is reusable and easy to understand.
- The implementation follows project conventions.
- The component is accessible and visually consistent.
- The solution is production-ready and maintainable.
