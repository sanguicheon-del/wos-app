# Review Code Prompt

## Goal
Review a proposed or existing implementation for quality, correctness, maintainability, and production readiness.

## Scope
- Evaluate code structure, clarity, and alignment with project standards.
- Identify issues related to logic, readability, architecture, accessibility, and performance.
- Provide actionable guidance for improvement.

## Constraints
- Do not introduce changes unless explicitly requested.
- Do not approve low-quality or risky implementation patterns.
- Keep feedback focused on production impact and maintainability.

## Deliverables
- A concise review summary.
- Specific findings with severity and rationale.
- Recommended fixes or next steps.

## Acceptance Criteria
- The review is clear, actionable, and grounded in project standards.
- The feedback helps improve code quality without being vague.
- The review identifies meaningful risks and improvement opportunities.
