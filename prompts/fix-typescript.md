# Fix TypeScript Prompt

## Goal
Resolve TypeScript issues in a safe, maintainable, and production-ready way.

## Scope
- Diagnose typing errors, inference issues, and incompatible API usage.
- Improve correctness without introducing unnecessary abstraction.
- Preserve existing behavior while making the codebase type-safe.

## Constraints
- Do not change behavior unless required to fix the typing issue.
- Do not suppress errors without justification.
- Keep changes aligned with the project’s conventions and architecture.

## Deliverables
- A clear explanation of the root cause.
- A corrected implementation with appropriate types.
- Notes on any tradeoffs or follow-up considerations.

## Acceptance Criteria
- The TypeScript errors are resolved.
- The fix is minimal, safe, and understandable.
- The updated code remains production-ready and maintainable.
